🔐 تسجيل الطلاب وربط المنصة

سجّل حسابًا بالبريد الإلكتروني، واحفظ ملف الطالب وتقدمه في قاعدة بيانات سحابية مشتركة بعد إعداد Firebase.

1) إعداد Firebase

لم يتم إعداد Firebase بعد. الحسابات السحابية غير مفعّلة.

تجد هذه القيم في Firebase Console ← Project settings ← Your apps. إعدادات Web العادية ليست كلمة مرور، لكن لا تشارك أي مفاتيح إدارية أو Service Account.

2) حساب الطالب

لم يتم تسجيل الدخول.

التسجيل ينشئ دور student فقط. لا يمكن للطالب اختيار دور المدير من هذه الواجهة.

3) مزامنة تقدم Python

بعد تسجيل الدخول، يمكنك رفع تقدم هذا الجهاز إلى حسابك أو تحميل التقدم المحفوظ في حسابك.

لا توجد عملية مزامنة حتى الآن.

4) قواعد أمان Firestore المطلوبة

انسخ القواعد التالية إلى Firestore → Rules قبل استخدام بيانات حقيقية. صلاحية المدير تعتمد على custom claim يضبطه مسؤول موثوق من بيئة خادم آمنة.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function signedIn() { return request.auth != null; }
    function isOwner(uid) { return signedIn() && request.auth.uid == uid; }
    function isAdmin() {
      return signedIn() && request.auth.token.admin == true;
    }

    match /users/{uid} {
      allow read: if isOwner(uid) || isAdmin();
      allow create: if isOwner(uid)
        && request.resource.data.role == 'student';
      allow update: if isOwner(uid)
        && request.resource.data.role == resource.data.role
        && request.resource.data.role == 'student';
      allow delete: if isAdmin();
    }

    match /progress/{uid} {
      allow read, create, update: if isOwner(uid);
      allow delete: if isOwner(uid) || isAdmin();
    }

    match /courses/{courseId} {
      allow read: if true;
      allow write: if isAdmin();
    }
    match /lessons/{lessonId} {
      allow read: if true;
      allow write: if isAdmin();
    }
  }
}
مهم: لا تمنح نفسك أو أي طالب صلاحية admin من واجهة الموقع. تعيين custom claims يتم فقط من خادم موثوق باستخدام Firebase Admin SDK، ولا تضع مفتاح Service Account داخل ملف HTML.

الخطوات المتبقية للنشر

  1. أنشئ Firebase project وتطبيق Web.
  2. فعّل Authentication → Email/Password.
  3. أنشئ Firestore Database والصق قواعد الأمان أعلاه.
  4. أدخل إعدادات Web في القسم الأول واضغط الاتصال.
  5. اختبر إنشاء حساب طالب وتسجيل الدخول والمزامنة.
  6. انشر الموقع على استضافة HTTPS، واطلب من شخص بالغ موثوق مراجعة إعدادات الأمان قبل استقبال طلاب حقيقيين.

إدارة الطلاب
